# Security Policy

## Supported Versions

Security fixes are evaluated for the current default branch. This repository does not currently publish versioned releases.

## Reporting a Vulnerability

Do not post potential security vulnerabilities, sensitive logs, or personal data in public issues. Use the repository's private security-advisory reporting feature when it is enabled, or contact the repository owner through an approved private channel.

Include:

- A clear description of the issue and potential impact.
- Reproduction steps or a minimal proof of concept.
- Affected Windows and PowerShell versions.
- Any suggested mitigations.

The application is designed to store work-timing data locally. Reports should avoid including real work-history records, account identifiers, file paths, or other sensitive data unless the recipient has explicitly authorized the transfer.
